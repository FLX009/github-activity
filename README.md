## GitHub User Activity
This is CLI application made on python and utilizes the GitHub API.
I   t can output the most recent public events from a GitHub user.

# How to install
```bash
git clone https://github.com/FLX009/github-activity.git
cd github-activity
```

# How to use
```bash
#this will print the last events of the user
python gh-activity.py <username>
```
